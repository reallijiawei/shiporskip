# Steve Jobs 完整时间线 (1955-2011)

## 概览

Steve Jobs 的一生可以划分为五个阶段，每个阶段都有明确的思想转折：

| 阶段 | 时间 | 核心特征 |
|------|------|----------|
| 形成期 | 1955-1976 | 从硅谷车库少年到技术理想主义者 |
| Apple I 期 | 1976-1985 | 天才但失控的产品暴君 |
| 流放期 | 1985-1997 | NeXT 学会平台思维，Pixar 学会信任创意人才 |
| 黄金期 | 1997-2011 | 所有教训的综合，从产品哲学家到商业传奇 |
| 遗产期 | 2011- | 定义了整个移动计算时代 |

---

## 详细时间线

### 第一阶段：形成期 (1955-1976)

| 年份 | 事件 | 意义 |
|------|------|------|
| 1955.02.24 | 出生于旧金山，生父母为 Joanne Schieble 和 Abdulfattah Jandali；被 Paul 和 Clara Jobs 收养 | 被收养的身份成为他终身驱动力的一部分——"被选择"的感觉让他既渴望证明自己，又对控制有执念 |
| 1959 | 全家搬到加州 Mountain View（未来的硅谷核心） | 生长在惠普工程师和半导体公司环绕的环境中，技术基因从小渗透 |
| 1968 (13岁) | 直接打电话给惠普创始人 Bill Hewlett 要零件，获得暑期实习 | 早期就展现出打破层级、直接行动的特质——这后来成为他面对任何权威时的默认模式 |
| 1969 | 通过 Bill Fernandez 认识 Steve Wozniak | 这段友谊定义了整个个人电脑时代 |
| 1971 | 与 Wozniak 合作制造"蓝盒子"电话盗打装置 | 第一次将技术能力变成产品，学到了"把黑客变成产品"的模式 |
| 1972.09 | 进入俄勒冈 Reed College | 接触到反文化运动、东方哲学、嬉皮士精神 |
| 1973 (一学期后) | 退学，但继续旁听课程，尤其是 Robert Palladino 的书法课 | **关键转折点**：书法课让他理解了字体排印之美，这直接导致了 Macintosh 的比例字体——技术与人文的第一次融合 |
| 1974.02 | 进入 Atari 工作 | 第一次在商业公司中体验产品开发 |
| 1974 年中 | 与 Daniel Kottke 前往印度寻找 Neem Karoli Baba（已去世） | **关键转折点**：七个月的印度之行让他接触佛教和极简主义，回来后剃光头、穿传统服装，开始跟随 Zen master Kōbun Chino Otogawa 修禅 |
| 1975 | 参加 Homebrew Computer Club 聚会 | 亲眼见证个人计算机运动的萌芽 |
| 1976.03 | Wozniak 完成 Apple I 设计，Jobs 提议销售 | Jobs 的直觉：技术必须变成产品才能改变世界 |
| **1976.04.01** | **与 Wozniak、Ronald Wayne 在父母车库创立 Apple Computer** | 21 岁，用卖掉大众巴士和惠普计算器的钱创业 |

### 第二阶段：Apple I 期 — 天才暴君 (1976-1985)

| 年份 | 事件 | 意义 |
|------|------|------|
| 1976 | Paul Terrell 订购 50 台完整 Apple I，每台 $500 | 第一个商业验证 |
| 1977.04 | 在 West Coast Computer Faire 发布 Apple II | Apple II 成为第一款成功的消费级个人电脑，Apple 从小作坊变成真正的公司 |
| 1978.05.17 | 女儿 Lisa Brennan-Jobs 出生，Jobs 最初否认亲子关系 | 暴露了年轻 Jobs 的冷酷和逃避——DNA 测试确认亲子关系（概率 94.1%） |
| 1979 | 参观 Xerox PARC，看到 Alto 的鼠标驱动图形界面 | **关键转折点**：他意识到图形界面是未来，但 Xerox 自己没有能力把它变成产品。"好的艺术家抄袭，伟大的艺术家偷窃"——这句话从这里来 |
| 1980 | Apple 上市，首日市值 $12 亿；Jobs 身价超过 $2.5 亿 | 25 岁成为亿万富翁，但也开始被财富和权力改变 |
| 1981 | Jobs 接管 Jef Raskin 的 Macintosh 项目 | 将 Mac 从低成本电脑重新定义为"为普通人设计的图形界面电脑" |
| 1983 | 从百事可乐挖来 John Sculley 任 CEO | "你想一辈子卖糖水，还是跟我一起改变世界？"——这句话后来反噬了他 |
| 1983 | Apple Lisa 发布，商业失败 | 封闭架构 + 过高定价 = 失败。Jobs 没有从这个教训中学到足够多 |
| **1984.01.22** | **超级碗播放 "1984" 广告** | 史上最伟大的电视广告之一，将 Apple 品牌与反叛精神绑定 |
| **1984.01.24** | **Macintosh 正式发布** | 第一款商业成功的图形界面个人电脑。Jobs 的产品直觉被验证——但他的管理方式也埋下了祸根 |
| **1985.05** | **Sculley 向董事会提议将 Jobs 逐出 Macintosh 部门** | Jobs 的封闭架构路线与 Sculley 的开放架构路线冲突，董事会站队 Sculley |
| **1985.09.17** | **Jobs 从 Apple 辞职，卖掉几乎全部 Apple 股票** | **人生最大的转折点**：被自己创立的公司开除，公开羞辱。他说这"是一剂猛药，但病人需要它" |

### 第三阶段：流放期 — NeXT 与 Pixar (1985-1997)

| 年份 | 事件 | 意义 |
|------|------|------|
| **1985** | **创立 NeXT Inc.，投资 $1200 万** | 目标：为高等教育市场打造完美的工作站。证明即使被 Apple 驱逐，他仍然能创造伟大的产品 |
| 1986 | Ross Perot 大举投资 NeXT | 外部资本验证了 Jobs 的愿景 |
| **1986** | **以约 $1000 万买下 Lucasfilm 的电脑图形部门，更名为 Pixar** | **关键转折点**：这笔投资最初是出于对电脑图形的技术兴趣，最终改变了整个动画产业 |
| 1988.10.12 | NeXT 电脑在旧金山盛大发布，起价 $6,500 | 技术上令人惊叹（对象操作系统、镁合金机箱），但太贵了——只有卖了 50,000 台 |
| ~1990 | 在斯坦福商学院遇到 Laurene Powell | 私人生活的转折点，他开始建立稳定的家庭 |
| **1990** | **Tim Berners-Lee 用 NeXT 电脑发明了万维网** | NeXTSTEP 的技术架构比它的商业成功更重要——它证明了 Jobs 对平台的直觉是对的 |
| **1991.03.18** | **与 Laurene Powell 结婚** | 从否认女儿的父亲变成了丈夫和父亲 |
| 1993 | NeXT 硬件业务失败，转型为纯软件公司 | **关键转折点**：Jobs 学到了——技术卓越不等于商业成功，定价和市场定位同样重要 |
| 1994 | NeXT 报告首个年度利润 $103 万 | 软件业务终于找到可持续模式 |
| **1995.11.22** | **《玩具总动员》上映——史上第一部电脑动画长片** | **关键转折点**：Pixar 的成功证明了 Jobs 的新领导方式——他学会了信任创意人才，不再事事微观管理。Pixar 的 Floyd Norman 说他变成了"一个成熟、温和的人" |
| 1996 | NeXT 发布 WebObjects | 企业级 Web 应用开发平台 |
| **1996.12** | **Apple 以 $4.29 亿收购 NeXT** | NeXTSTEP 成为 Mac OS X 的技术基础。Jobs 以"救世主"身份回到 Apple |
| **1997.07** | **Jobs 成为 Apple 实际掌权人** | CEO Gil Amelio 被董事会驱逐，Jobs 重新掌控公司 |
| 1997.09.16 | 正式被任命为临时 CEO（"iCEO"） | 仅领取 $1 年薪，重新定义了高管薪酬的象征意义 |

### 第四阶段：黄金期 — 综合与创造 (1997-2011)

| 年份 | 事件 | 意义 |
|------|------|------|
| **1997** | **砍掉 Newton、Cyberdog、OpenDoc 等多个项目** | **关键转折点**：回归后的第一件事是做减法。"专注就是对 1000 个好主意说不"——这是 NeXT 和 Pixar 教给他的最重要的一课 |
| **1998** | **发布 iMac** | 半透明果冻色一体机，一年卖出 200 万台。证明了"技术+设计+情感"的综合能力。"i"前缀从此成为 Apple 的品牌标识 |
| 2000 | 去掉"临时"头衔，成为正式 CEO | 从"临时工"到正式掌舵，Apple 股价和产品线都进入上升轨道 |
| **2001** | **发布 iPod + iTunes** | **关键转折点**：Apple 从电脑公司变成消费电子公司。"把 1000 首歌装进口袋"——这句广告语定义了整个数字音乐时代 |
| **2003** | **iTunes Store 上线** | 数字内容分发的革命。到 2008 年，Apple 成为美国第二大音乐零售商（仅次于沃尔玛） |
| 2003.10 | 被诊断出胰腺神经内分泌肿瘤 | 罕见的可治疗类型，但 Jobs 选择推迟手术九个月，尝试替代疗法——这个决定后来被广泛讨论 |
| 2004.07 | 接受胰腺切除手术（Whipple 手术） | 员工公开信中首次披露病情 |
| **2006** | **Pixar 与迪士尼合并，交易额 $74 亿** | Jobs 成为迪士尼最大的个人股东（约 7-8%）。从被 Apple 驱逐的失败者，变成了好莱坞最有权势的人之一 |
| **2007.01.09** | **发布 iPhone** | **人生最重要的产品**：重新定义了手机、计算和人类与技术的关系。公司从 "Apple Computer Inc." 更名为 "Apple Inc." |
| 2008 | App Store 上线 | 开创了移动应用经济，创造了数百万开发者就业机会 |
| 2009 | 接受肝移植手术；六个月病假，Tim Cook 代理日常运营 | 健康问题公开化，但 Jobs 仍在 2009.09.09 的发布会上强势回归 |
| **2010.04.03** | **发布 iPad** | 创造了现代平板电脑市场，一年卖出 1500 万台 |
| 2011.01 | 宣布再次病休 | 第三次也是最后一次病休 |
| **2011.08.24** | **辞去 Apple CEO，推荐 Tim Cook 继任** | 辞职信中写道："我总是说，如果有一天我无法履行 CEO 的职责，我会第一个告诉你们。不幸的是，这一天来了。" |
| **2011.10.05** | **在 Palo Alto 家中去世，享年 56 岁** | 死因为胰腺肿瘤导致的呼吸衰竭。姐姐 Mona Simpson 记录的遗言："Oh wow. Oh wow. Oh wow." |
| 2011.10.16 | 葬礼在斯坦福大学举行，安葬于 Alta Mesa 纪念公园（无标记墓碑） | 按照他一贯的极简主义——连墓碑都不要 |

## 思想转折点总结

### 转折点 1：Reed College 书法课 (1973)

> "如果我没有退学，我就不会旁听那门书法课，个人电脑可能就不会有现在这样美妙的字体。"

从纯粹的技术思维第一次转向"技术必须与人文结合"。这是 Jobs 产品哲学的种子。

### 转折点 2：印度之行与禅宗修行 (1974)

七个月的印度旅行和此后的禅宗修行，给了他三样东西：
- **极简主义的审美直觉**：少即是多
- **直觉高于分析的决策方式**：他后来反复说"要相信直觉"
- **对"开悟"的追求**：产品不只是工具，而是通往更好生活的方式

### 转折点 3：被 Apple 驱逐 (1985)

这是他一生中最痛苦的经历，但也是最有价值的。它教会他：
- 聪明不等于能管理——他必须学会与人合作
- 创始人不等于永远拥有公司——权力是暂时的
- 失败是重新开始的机会——"被苹果开除是我人生中最好的事"

### 转折点 4：NeXT 的失败与成功 (1985-1996)

NeXT 硬件失败了（只卖了 50,000 台），但软件成功了（NeXTSTEP 成为 macOS 的基础）。这教会他：
- **平台思维比产品思维更重要**：做一个好产品不够，要做一个能支撑无数好产品的平台
- **定价和市场定位是产品的一部分**：技术再好，价格不对就是死路
- **耐心等待回报**：NeXT 的技术在十年后才真正发挥作用

### 转折点 5：Pixar 的信任实验 (1986-2006)

在 Pixar，Jobs 学会了他以前完全不具备的能力——信任创意人才。Edwin Catmull 的方法是：不同意时等一周再谈，有时候讨论持续几个月。大约三分之一的时间 Jobs 让步，三分之一 Catmull 让步，剩下三分之一 Jobs 直接让 Catmull 按自己的方式做。

这与早期 Apple 的 Jobs 判若两人。他从"我永远是对的"变成了"找对的人，让他们做对的事"。

### 转折点 6：iPhone 重新定义计算 (2007)

iPhone 不只是一个产品发布——它是 Jobs 所有哲学的终极表达：
- **技术与人文的交汇**：手机不只是打电话的工具，而是"你口袋里的整个生活"
- **端到端控制**：硬件 + 软件 + 服务 = 完整体验
- **预见未来**：引用 Wayne Gretzky——"滑向冰球要去的地方，而不是它现在的位置"

## 每个阶段的核心产品/决策

| 阶段 | 核心产品/决策 | 决策逻辑 |
|------|--------------|----------|
| Apple I 期 | Apple II、Macintosh | "让每个人都能用上电脑"——但执行方式过于封闭和独裁 |
| 流放期 | NeXTSTEP、Toy Story | 技术平台思维 + 信任创意人才——失败中提炼出真正的智慧 |
| 黄金期 | iMac、iPod、iPhone、iPad | 所有教训的综合：减法优先、平台思维、端到端控制、信任团队 |
